========== 1 ==========
【提问】
把后端编译跑通，然后冒烟测试统计 / 上传 / 社区接口是否正常。

【收获】
后端 BUILD SUCCESS；发现并修复 UploadService 的 UrlResource 受检异常。统计口径、上传、社区发帖逐项 curl 验证通过。

========== 2 ==========
【提问】
老师明天要求把项目发布给同学测试，需要做什么准备？

【收获】
理清部署三件事：数据持久化（H2 文件库）、内网穿透（cpolar）、预置演示数据。学会用 cpolar 把本地服务暴露成公网链接。

========== 3 ==========
【提问】
注册报错 403 是什么问题？

【收获】
定位是 CORS：隧道带 cpolar 的 Origin，后端只放行 localhost。通过在 Vite 代理里剥 Origin 头解决（同源代理本不需要 CORS）。

========== 4 ==========
【提问】
手机打开是白屏怎么办？

【收获】
Vite dev server 在手机 / 隧道下不兼容，改用生产构建 vite preview（打包成静态文件，兼容性好、加载快）。

========== 5 ==========
【提问】
手机端 UI 被挤扁、很丑，怎么改？

【收获】
做了移动端自适应：底部导航栏（像原生 App）、登录卡自适应、卡片窄屏竖排。理解了响应式布局（媒体查询 + el-col 的 xs/sm 断点）。

========== 6 ==========
【提问】
H2 报 file is locked 怎么回事？

【收获】
旧的 java 进程没退干净、占着数据库文件。用 taskkill 杀掉残留进程解决，理解了文件锁。

========== 7 ==========
【提问】
队友登管理员界面，为什么他的数据和我的不一样？

【收获】
搞清「文件快照」和「实时共享」的区别：文件复制是快照不会同步，实时要看同一份数据要么直连后端、要么用共享数据库（MySQL）。
