## 遇到的问题与解决
- **Vite 拦截 cpolar 域名返回 403** → 加 `allowedHosts` 放行任意域名。
- **后端 CORS 拦隧道 Origin 返回 403** → 在 Vite 代理里剥掉 Origin 头（同源代理本不需要 CORS）。
- **手机白屏**（dev server 在手机/隧道下不兼容）→ 改用生产构建 `vite preview`。
- **H2 文件被残留进程锁住**（`file is locked`）→ 定位并杀掉残留 java 进程。
- **队友看数据是「快照」不是「实时」** → 搞清「文件库快照」和「直连后端实时共享」的区别。
